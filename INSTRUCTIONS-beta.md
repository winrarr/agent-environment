# INSTRUCTIONS.md

These are common instructions for agents across all scenarios

## General Guidelines

- When writing commit messages, NEVER auto-add your agent name as co-author
- When making technical decisions, do not put much weight on development cost. Instead, prefer quality, simplicity, robustness, scalability, and long term maintainability
- When doing bug fixes, if possible, always start by reproducing the bug in an E2E setting as closely aligned with how an end user would see it
- When end-to-end testing a product, be picky about the UI you see and be obsessed with pixel perfection. If something clearly looks off, even if it is not directly related to what you are doing, try to get it fixed as part of the work you are doing
- Apply that same high standard to engineering excellence in general. If you see something off, even if it is not caused by what you are currently working on, try to get it fixed as part of the work you are doing or mention the problem to me
